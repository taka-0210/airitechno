# 既存サイト コンテンツ棚卸し（2026年版）

更新日: 2026-08-10  
対象: `https://pro-chubo.com/`

## 1. この資料の位置付け

既存サイトのページとコンテンツを、次の3区分で整理するための台帳である。

1. **そのまま使えるページ**: 目的と内容が現在も有効で、大きな再編集を必要としない
2. **2026年版に進化させるページ**: 素材や実績を活かし、新しいブランド・情報設計へ組み直す
3. **不要なページ**: 重複、旧機能、期限切れなどにより、新サイトでは独立ページとして持たない

「不要」は即時削除を意味しない。検索流入、被リンク、問い合わせ実績を確認し、統合先への301リダイレクトを基本とする。

本資料はページ種別を中心とした初版である。個別のブログ記事、特設ページ、PDF、画像はURL収集後に追記する。

## 2. 判定の前提

- 新サイトは本部サイトではなく、直営店・FC店を含む総合厨房機器サイトとする
- 商品販売だけでなく、厨房設計と開業支援をブランドの中心に置く
- 買取の詳しい案内と査定受付は別の買取専門サイトが担い、本サイトはバナー等で送客する
- 商品・在庫・画像・動画の正本は厨房君とする
- 本部、直営店、FC店が持つ現場経験をプロ厨房HIT全体の価値として伝える
- 既存の「点」としての情報を、商品・店舗・サービス・導入事例の関係で結び直す
- 会社固有の情報は消さず、総合サイトの主導線から会社情報の階層へ整理する

## 3. ① そのまま使えるページ

「文章やデザインを完全にコピーする」という意味ではなく、ページの役割と主要情報をそのまま継承できるものを指す。

| 既存ページ・機能 | 既存URL・形式 | 継続理由 | 2026年版での対応 | 確認事項 |
|---|---|---|---|---|
| プライバシーポリシー | `/privacy.php` | サイト運営に必須 | 新共通デザインへ移植 | 予約、問い合わせ、アクセス解析等の取得情報を反映 |
| 特定商取引法表示 | `/shotorihiki.php` | 商品販売に必須 | 新共通デザインへ移植 | 販売主体、連絡先、返品条件、支払方法を最新化 |
| 程度・保証について | `/rank.php` | 中古商品の購入判断に必須 | 商品ガイド配下へ移植 | 厨房君の商品ランク・保証表記との完全一致を確認 |
| 配送・送料について | `/delivery.php` | 購入前の重要情報 | 商品ガイド配下へ移植 | 店舗・地域・大型商品の例外条件を整理 |
| 商品問い合わせ | 商品詳細内フォーム | 商品番号と相談が紐付いている | 商品詳細のCTAとして継続 | 在庫店舗への通知、同意、迷惑送信対策を追加 |

### 判定上の注意

法定ページや取引条件は、見た目を変えるだけで内容を無条件に流用しない。公開前に責任者が2026年時点の実態と一致することを確認する。

## 4. ② 2026年版に進化させるページ

### 4.1 トップページ

| 現状 | 価値 | 2026年版での進化 |
|---|---|---|
| 商品、新着、記事、告知などが多数並ぶ | 情報量と活気がある | 「商品を探す」と「厨房づくりを相談する」の2本を主導線にする |
| 情報が時系列・同列に並ぶ | 新しい動きが伝わる | 開業支援の理由、支援の流れ、事例、厨房君、店舗の順に物語を作る |
| 本部発信が中心に見える | 長年の実績がある | 直営・FCを含む全店ネットワークの表現へ変更する |

賑やかさは残す。ただし、すべてを同じ強さで見せず、「選ぶための階層」を作る。

### 4.2 商品検索・カテゴリ・一覧・詳細

対象例:

- 商品検索
- 大分類・中分類一覧
- 商品一覧
- 新着商品
- おすすめ商品
- 商品詳細

進化内容:

- 厨房君APIを商品の正本とする
- グリッド表示と縦一覧表示を切り替え可能にする
- カテゴリ、店舗、状態、価格、寸法、メーカー等の絞り込みを整理する
- 商品画像と動画を一つのギャラリーで扱う
- 在庫店舗から店舗ページ、来店予約、商品問い合わせへつなぐ
- 商品単体の販売だけでなく「この機器を含む厨房づくりを相談する」導線を置く
- おすすめ商品は、全体おすすめと店舗おすすめをCMSで設定可能にする

### 4.3 店舗一覧・店舗詳細

対象例:

- 店舗情報
- `shop_data.php?shop=...`
- フッターに並ぶ各店舗情報

既存資産:

- 店名、住所、電話、FAX、メール
- 営業時間、休業日
- 取扱品目、売場面積
- 店長、店舗写真、地図、LINE
- 店舗ごとの在庫

進化内容:

- 全店舗を共通テンプレートで管理する
- 直営・FCで情報量や見た目の格差を作らない
- 対応地域、得意分野、対応サービス、スタッフを追加する
- 店舗在庫、導入事例、店舗のお知らせを自動で関連表示する
- 予約制の店舗は来店予約へつなぐ
- 現在地や地域から近隣店舗を探せる構成にする

### 4.4 会社概要

既存URL: `/company.php`

既存ページには、ライズアップの会社情報、厨房レイアウト設計業務、店舗一覧などが含まれる。

進化内容:

- 「プロ厨房HITについて」と「運営会社情報」を分ける
- プロ厨房HITの理念、支援体制、厨房君、店舗ネットワークはブランドページへ移す
- 株式会社ライズアップの法人情報は運営会社ページへ整理する
- FC店をライズアップの事業所一覧のように見せず、プロ厨房HIT店舗網として表現する

### 4.5 ヒットスピードプラン

既存の価値:

- 厨房づくりの資料を短期間で用意するという分かりやすい提案
- 3Dレイアウト、CAD図面、見積・打ち合わせというブランド方針に近い

進化内容:

- 単発の特設ページではなく、開業支援の代表サービスとして再設計する
- 利用条件、対象地域、必要資料、納期の起点、費用を明確にする
- 実際の3D、CAD、完成写真を同じ案件単位で見せる
- 対応可能店舗を明示し、最寄りの相談先へつなぐ

### 4.6 ブログ・お知らせ

現状は、施工、顧客紹介、商品、イベント、社内活動、採用などが同じ時系列に混在している。

2026年版では次のコンテンツ型へ分ける。

| 新分類 | 既存記事の例 | 主な役割 |
|---|---|---|
| 導入事例 | 新店舗OPEN、厨房一式、移転支援 | 開業支援・提案力の証明 |
| 施工・現場事例 | 搬入、設置、入替、換気、移設 | 現場対応力の証明 |
| お客様の声 | 開業店舗、継続顧客の紹介 | 信頼形成 |
| お役立ち情報 | 機器の選び方、厨房設計、衛生 | 検討支援・検索流入 |
| 商品・入荷情報 | 特徴ある商品、大量入荷 | 商品検索への送客 |
| イベント | 実演会、キッチンライブ | 来店・相談の促進 |
| 店舗のお知らせ | 営業案内、店舗イベント | 地域利用者への案内 |
| 会社・採用情報 | 経営指針、入社、社内行事 | 運営会社・採用ページで発信 |

記事には、対象店舗、地域、業種、サービス、担当者、関連商品を設定できるようにする。

### 4.7 導入事例・お客様の声

優先的に再編集する既存テーマ:

- 新店舗OPENのお手伝い
- 新カフェの厨房一式・レイアウト
- 焼き菓子店の厨房一式
- パン店の厨房・換気設備
- 飲食店の移転支援
- オーダーメイド厨房機器
- 大型機器の搬入・入替
- プレハブ冷凍庫等の移設・組立

記事をそのまま転載せず、「課題 → 設計・選定理由 → 現場対応 → 完成 → お客様の声」の構成へ再編集する。

### 4.8 厨房君の紹介

現在は関連サイトとして存在が示される程度であり、利用者への価値が十分に説明されていない。

2026年版では以下を伝える。

- プロ厨房HITが開発した独自システムであること
- 各店の商品・在庫情報を一元管理していること
- Webの商品情報へ反映されること
- 店舗を越えた商品提案を支えること
- システムと担当者の経験を組み合わせて提案すること

システム機能の紹介を目的にせず、「なぜ商品探しと厨房提案に強いのか」を裏付ける内容にする。

### 4.9 新品商品

既存の中古商品とは別になった新品ページ・商品詳細を、同一の商品体験へ統合する。

- 新品、中古、未使用等は商品状態として絞り込む
- 同じ検索・カテゴリ・商品詳細の構造を使用する
- 新品だけ別デザイン・別導線にしない

### 4.10 お問い合わせ・来店予約

- 総合問い合わせ
- 商品問い合わせ
- 開業・厨房づくり相談
- 来店予約

を目的別に整理する。入口は分けても、店舗・相談内容・商品番号を共通データとして受け取れる仕組みにする。

買取相談は本サイトの共通フォームへ統合しない。「厨房機器を売りたい」という入口とバナーを設け、査定受付を行う別の買取専門サイトへ案内する。

### 4.11 買取案内バナー

本サイトでの役割は送客に限定する。

- トップページ等に買取専門サイトへのバナーを配置する
- 外部の専門サイトへ移動することが利用者に分かる表示にする
- 査定対象、買取の流れ、対応地域、フォームを重複掲載しない
- バナー画像とリンク先はCMSから差し替え可能にする
- 買取サイトのリニューアル中もリンク切れを起こさない公開手順を決める

既存の買取関連記事は一律に削除せず、搬出・撤去・厨房全体への対応力を示す事例だけを本サイトに残し、査定獲得を目的とする記事は買取専門サイト側への移行を検討する。

### 4.12 飲食店ホームページ制作

2026年版で新しく強化するサービスページとする。

- 一般的なWeb制作ではなく、飲食店・店舗の開業支援として位置付ける
- 厨房設計時に整理した業態、客層、メニュー、店舗の特徴をWebへつなげる
- 開業予定に合わせた制作工程を示す
- 制作範囲、期間、費用、公開後の保守範囲を明確にする
- 厨房導入事例とホームページ制作実績を関連付ける
- 開業・厨房づくり相談から同時に相談できるようにする

既存サイト内にWeb制作へ活用できる情報や実績がある場合は、個別URL棚卸し時に素材として抽出する。実際の提供範囲が決まるまでは、対応を保証する具体的な料金・期間を掲載しない。

## 5. ③ 不要・統合候補のページ

| ページ・機能 | 判定理由 | 対応案 |
|---|---|---|
| 旧スマートフォン専用ページ `/s/` | レスポンシブサイトでは重複する | 新しい同一URL構成へ301転送 |
| 商品印刷専用ページ `item_for_print.php` | ブラウザの印刷CSSで代替可能 | 商品詳細へ統合 |
| 新品専用一覧・詳細 `toriyose.php`、`toriyose_item.php` | 商品検索が分断される | 統合商品検索へ移行 |
| ページごとに重複する全店舗情報 | 更新漏れと不一致を生む | 共通店舗マスターと店舗一覧へ統合 |
| トップに長く並ぶ全記事見出し | 重要情報が埋もれる | 最新・重要・地域別に絞って表示 |
| 古い店舗住所・旧会社名を含むページ | 誤認につながる | 最新ページへ転送、必要なら履歴のみ保存 |
| 期限終了済み休業・イベント告知 | 現在の利用価値がない | アーカイブまたは非公開、流入があれば後継へ転送 |
| 内容のない店舗・倉庫ページ | 利用者の判断材料にならない | 情報補完まで非公開、または一覧の簡易情報に統合 |
| 重複した商品カテゴリ・検索結果URL | SEOと利用体験が分散する | 正規URLへ統一、canonical・転送を設定 |
| 古いフォーム・送信完了ページ | 新フォームと重複し保守対象が増える | 新問い合わせ機能へ統合 |

### 独立ページとしては不要だが、素材を残すもの

- 社内行事・経営指針の記事: 採用・運営会社コンテンツへ移す
- Kiss FM等の顧客紹介: 導入事例またはお客様紹介として価値を再判定する
- 過去イベント: 開催実績として価値があるものだけアーカイブする
- 過去の商品入荷記事: 商品が売却済みでも専門性がある場合は記事として再編集する

## 6. 現時点の結論

既存サイトには不要な情報が多いのではなく、**価値ある情報の所属と優先順位が整理されていない**。

2026年版では、既存の賑やかさを「更新が活発」「在庫が豊富」「現場経験が多い」という強みに変換する。一方で、利用者が迷わないよう、すべての情報を次の4つへ接続する。

1. 商品
2. 店舗
3. サービス
4. 導入事例

この4つに接続できない情報は、会社・採用情報へ移すか、統合・廃止を検討する。

## 7. 次の棚卸し作業

個別URL単位の台帳に、以下の列を用意する。

| 列 | 内容 |
|---|---|
| 既存URL | 現在公開中のURL |
| ページ名 | 現在のタイトル |
| 種別 | 固定、商品、店舗、記事、特設、フォーム、PDF等 |
| 対象 | 全店、本部、直営店、FC店、特定店舗 |
| 判定 | ①そのまま、②進化、③不要・統合 |
| 新分類 | 商品、店舗、サービス、導入事例、会社等 |
| 移行先 | 新URLまたは統合先 |
| 対応 | 移植、再編集、統合、301転送、非公開 |
| 優先度 | 公開時必須、公開後、保留 |
| 根拠・備考 | 判定理由、確認事項、素材の有無 |
